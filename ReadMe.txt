FASTLANE LOGISTIC — SITE VITRINE

Site statique en français : transport minier, marchandises et logistique en Guinée.
Domaine principal : https://www.fastlanelogisticgn.com/

Pages : index.html, a-propos.html, pourquoi-nous.html, appels-offres.html, contact.html.
Styles partagés : styles.css. Interactions : script.js.
Les photos WebP et leurs variantes mobiles sont dans images/ ; les originaux sont conservés.

SEO
Chaque page contient un titre, une description, une URL canonique et des données structurées.
robots.txt indique le sitemap.xml, qui référence les cinq URL canoniques.
Après publication, soumettre https://www.fastlanelogisticgn.com/sitemap.xml dans Google Search Console.
La publication du sitemap ne garantit pas l'indexation ni une position dans les résultats.

CONTACT
Le formulaire ouvre la messagerie du visiteur avec un e-mail prérempli.
Le visiteur doit envoyer le message depuis sa messagerie ; aucun serveur de formulaires n'est configuré.

RENDER
Dépôt : Faraleno2022/fastlanelogisticwebsimple, branche main.
Site statique, commande de build vide, répertoire publié : .
Les commits poussés sur main déclenchent le déploiement automatique configuré dans Render.
La validation du domaine et du certificat HTTPS se fait dans Custom Domains.

APERÇU LOCAL
Servir ce dossier avec un serveur HTTP statique et ouvrir sa racine dans le navigateur.
